# 헤어 어게인 EP.0 쇼츠: "탈모 고민 때문에 미용실 8곳 돌아봤습니다"

- 원본: 블로그 글 「탈모 고민 시작됐다면? 미용실 8곳 돌아보고 두피 홈케어까지 알아본 이유」
- 영상: `ep00-hair-again.mp4` (1080×1920, 30fps, 30초. 오디오 트랙은 무음이라 녹음이나 음악을 덧입혀야 함)
- 미리보기: `index.html`을 브라우저로 열면 반복 재생됩니다
- 다시 만들기: `node render.js`를 실행합니다 (Playwright와 ffmpeg가 필요)

내레이션은 1초에 4.5~5음절 정도로 맞췄습니다. 그대로 읽으면 각 구간에 들어갑니다.
